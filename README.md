## Featured Projects

### 🚗 Ride-Sharing Route Optimizer & Fare Calculator
> *C++ · Dijkstra's Algorithm · SFML*

A grid-based ride-sharing simulation built entirely in C++. The application computes the **shortest path between pickup and drop-off points** using Dijkstra's algorithm and calculates fares dynamically based on route distance. A visual grid map is rendered in real time using **SFML**, making the routing logic immediately visible and interactive.

**Problems solved:**
- Efficient shortest-path computation across a city grid
- Dynamic fare estimation tied directly to computed route cost
- Real-time graphical map rendering without a game engine
